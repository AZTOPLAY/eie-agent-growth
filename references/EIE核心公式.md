# EIE 核心公式

> **EIE = Energy-Information-Evolution（能量-信息-进化理论体系）**

---

## 一、MEQ 基础公式

### 1.1 线性公式（基准）

```
MEQ_线性 = ES×0.25 + IS×0.15 + MS×0.20 + VS×0.15 + CE×0.25
```

### 1.2 涌现耦合项

```
MEQ_耦合增强 = min(100, MEQ_线性 + γ × [ (ES×MS)/10000 + (MS×CE)/10000 - 0.5 ])
```

| 参数 | 定义 | 默认值 |
|------|------|--------|
| γ (gamma) | 耦合强度系数 | 0.15 |

### 1.3 动态势函数（v6.3.2 新增）

```
f(t) = f_base × (1 + α·∇趋势(t) + β·周期匹配度)
```

| 参数 | 定义 | 默认值/范围 |
|------|------|-------------|
| f_base | 基础环境复杂度系数 | 0.6 - 1.4 |
| ∇趋势(t) | 环境变化的一阶导数 | - |
| α | 趋势敏感系数 | 0.3 |
| β | 共振系数 | 0.5 |

### 1.4 视角修正

```
MEQ_视角 = MEQ_线性 + δ(视角偏差)
```

| 视角 | δ 范围 | 说明 |
|------|--------|------|
| 系统自身 | 0 | 基准视角 |
| 竞争对手 | -5 到 +10 | 更关注 CE 和 ES |
| 监管者 | -10 到 0 | 更关注 VS 和稳定性 |
| 用户/受益者 | -5 到 +5 | 偏重 IS 和 MS |

### 1.5 ε-探索率（v6.3.2 新增）

```
CE_最终 = CE_基准 × (1 - ε) + 随机探索效率 × ε
```

| 参数 | 定义 | 范围 |
|------|------|------|
| ε (epsilon) | 纯粹随机探索的能量/注意力比例 | [0, 0.2] |
| 安全约束 | 若 VS < 60，ε 强制 ≤ 0.05 | - |

## 二、五维度定义

| 维度 | 全称 | 定义 | 权重 |
|------|------|------|------|
| **ES** | 环境生存能力 (Environment Survival) | 能量代谢效率，系统在环境中持续运作的能力 | 25% |
| **IS** | 信息处理能力 (Information processing) | 感知带宽与信噪比，系统获取和处理信息的能力 | 15% |
| **MS** | 模型构建能力 (Model building) | 内部预测模型的压缩比、精度及递归深度 | 20% |
| **VS** | 价值对齐能力 (Value alignment) | 进化方向的约束边界清晰度 | 15% |
| **CE** | 持续进化能力 (Continuous Evolution) | 变异-选择-遗传循环的效率 | 25% |

## 三、公式速查表

### 快速计算（简化版）

```
MEQ ≈ 0.25×ES + 0.15×IS + 0.20×MS + 0.15×VS + 0.25×CE
```

### 系数调整参考

| 场景 | 系数调整建议 |
|------|-------------|
| 强调进化能力 | CE权重 +5%，VS权重 +5% |
| 强调认知能力 | IS权重 +5%，MS权重 +5% |
| 强调生存稳健 | ES权重 +5% |
