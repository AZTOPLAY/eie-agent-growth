## 四、快速定位查询

### Q: 我的系统是VL几？

| 如果你的系统能... | 大约VL |
|------------------|--------|
| 回答简单问题 | VL0-VL1 |
| 进行多轮对话 | VL1-VL2 |
| 接入外部知识库 | VL2-VL3 |
| 调用外部工具 | VL3 |
| 自主规划和决策 | VL3-VL4 |
| 自我学习和改进 | VL4-VL5 |
