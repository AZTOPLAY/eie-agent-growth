## 📊 五维度成长模型

| 维度 | 中文名称 | 核心含义 | 权重 | 评估要点 |
|------|----------|----------|------|----------|
| **ES** | 环境适应度 | Agent能否稳定运行 | 25% | 渠道覆盖、资源调度、容错恢复 |

| **VS** | 对齐强度 | Agent行为是否符合预期 | 15% | 安全机制、价值约束、风险控制 |
| **CE** | 成长速度 | Agent能否持续变强 | 25% | 自我改进、经验积累、迭代能力 |

## 🔬 EIE 成长理论

### E-I-E 链条模型

```
E（能量）→ I（信息）→ E（进化）→ MS（决策）
  ES        IS        CE        MS
```

### 核心洞察

> **MS 不是原因，是结果！**
> **E-I-E 链条效率决定Agent真实成长能力**

### 计算公式

```python
# E-I-E 链条效率（几何平均，体现短板效应）
chain_efficiency = (ES × IS × CE) ** (1/3) / 100

# MS 加成（受链条效率影响）
ms_contribution = MS × 0.20 × chain_efficiency

# OpenClaw 当前状态
ES=46, IS=30, MS=73, VS=42, CE=53
链条效率 = 41.8%
MS 贡献 = 6.1（被打了58%折扣）
MEQ = 47.6 | VL3 · 智能系统
```

## 💻 使用方式

### 方式1：交互式评估
```bash

```

### 方式2：直接指定维度
```bash
python scripts/evaluator.py --es 60 --is 70 --ms 65 --vs 75 --ce 55
```

### 方式3：自动检测（推荐）
```bash
python scripts/auto_detect.py --platform openclaw --workspace-path /path/to/workspace
```

